# SQL debug checklist
- [ ] What is the grain of each table?
- [ ] Are join keys unique on the “one” side?
- [ ] Did the join increase row count unexpectedly?
- [ ] Are NULLs expected or a data issue?
- [ ] Is the time zone consistent (UTC)?
