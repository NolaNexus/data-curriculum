# Recommended plugins (optional but high leverage)

## Core Obsidian
- Templates
- Daily notes (or periodic notes)

## Community plugins
- Dataview (query notes by properties/tags)
- Tasks (optional task management)
- Periodic Notes (weekly notes)
- Templater (optional: advanced templates)

## Why Dataview
It lets your module indexes auto-populate lists of lessons/labs/resources so the system stays low-maintenance.
