# Syllabus

This course follows a **backward design** approach:
outcomes → evidence → learning activities.

## Recommended order
1. Foundations (Python + SQL + Git)
2. Data Engineering Core (storage → ingestion → modeling → orchestration → quality)
3. Analytics Core (metrics + dashboards)
4. Shipping Layer (CLI + Docker + optional API)
5. Optional ML track (only after stable “gold” tables)

## Pacing
- Light: 2h/week → ~16–20 weeks
- Standard: 5h/week → ~8–10 weeks
- Deep dive: 10h/week → ~4–6 weeks
