# North Star Outcome (v1)

1) Ingest raw data → store raw immutably (with provenance)  
2) Transform into modeled tables with tests  
3) Publish dashboard/report and/or API output  
4) Optional: train/score a model with proper evaluation  
5) One command + scheduled runs + logs
