# Rubrics

## Lesson rubric (pass/fail)
- Explain it plainly
- Do it once from memory
- Debug one failure mode

## Lab rubric (pass/fail)
- Produces artifact
- Contains evidence
- Notes next improvement

## Capstone rubric (v1)
- Reproducible
- Testable
- Observable
- Explainable metrics
- Idempotent reruns/backfills
