# Capstone demo checklist (5–10 minutes)

## The story (one sentence)
- “This pipeline helps me decide ________ by turning ________ into ________.”

## Proof path (show, don’t tell)
- [ ] Show raw storage (immutable) + metadata/provenance
- [ ] Show idempotent rerun proof (row counts/checksum or “no duplicates” test)
- [ ] Show dbt models + tests + docs
- [ ] Show one published output (dashboard/report/API)
- [ ] Click from a dashboard tile to the metric definition note
- [ ] Show schedule config and recent run logs (with run_id)
- [ ] Show how you backfill a date range
- [ ] Show how you handle a failure (runbook snippet)
