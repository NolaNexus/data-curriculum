# Hands‑On Learning (Practice Bank)

This section is optimized for **doing**, not consuming.

## How to use (15 seconds)
1. Pick **one** prompt from `Challenge_Prompts/`
2. Do it in your capstone repo (timebox 25–45 minutes)
3. Record evidence + what broke
4. Convert the result into:
   - a `Worked_Example`, or
   - a `Practice_Test`, or
   - a `Debug Pattern` note

## Recommended weekly rhythm (spaced + retrieval)
- 3 days/week: 1 challenge prompt
- 1 day/week: practice test (no notes) + fix gaps
- 1 day/week: refactor + write a worked example
