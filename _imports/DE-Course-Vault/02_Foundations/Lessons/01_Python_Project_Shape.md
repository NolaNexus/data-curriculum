# Goal
Build a Python repo that doesn’t hate you later: `pyproject.toml`, `src/`, tests, and a single command to run checks.

# Key ideas
- `src/` layout prevents accidental imports.
- Lockfiles reduce “works on my machine” pain.
- Tests are your future self’s immune system.

# Practice
1. Create a new repo.
2. Add a tiny module in `src/` and one pytest test.

# Checks
- I can run `pytest`.
- I can explain what `pyproject.toml` controls.
