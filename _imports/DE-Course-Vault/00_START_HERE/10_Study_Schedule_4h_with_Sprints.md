# Schedule: 4 hours/day (with optional 8-hour sprints)

## Default day (4 hours)
1) **Build (2h):** advance one gate (small artifact)
2) **Targeted learning (45m):** video/docs only to unblock build
3) **Retrieval + notes (45m):** practice test + 1 worked example/debug pattern
4) **Wrap (30m):** logbook + next tiny step + commit

## Sprint day (8 hours, 1–2x/week max)
- 4h deep build (end-to-end slice)
- 2h hardening (tests/logs/idempotency/backfill)
- 1h docs (runbook + metric definitions)
- 1h spaced review (redo earlier task w/o notes)

## Gate integration rule
Every day ends with: “Which gate moved today?” (even 1% counts).
