# Completeness checklist (vault quality)

## Navigation
- [ ] Every module has an index with ordered lessons + labs
- [ ] Every lesson has practice + checks
- [ ] Every lab has success criteria + evidence section
- [ ] Capstone has spec + milestone map + runbook + demo checklist

## Learning loop
- [ ] Templates exist (lesson, lab, debug, metric definition, weekly review)
- [ ] Assessments exist per module
- [ ] Troubleshooting section exists

## North Star coverage
- [ ] Ingestion patterns exist (files/APIs/scrape/logs)
- [ ] Raw immutability + provenance is taught
- [ ] Modeling (grain, facts/dims) is taught
- [ ] Quality gates are taught
- [ ] Scheduling + observability is taught
- [ ] Publishing outputs is taught

## Maintainability
- [ ] Resource capture process exists
- [ ] Naming + properties standards exist
