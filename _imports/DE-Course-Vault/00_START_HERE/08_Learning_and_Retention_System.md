# Learning + retention system (evidence-based)

This course is built around **practice testing (retrieval)** and **spacing** rather than rereading.

## The core loop (45–90 min)
1. **Worked example** (5–10 min): read a solved example and *self‑explain* each step
2. **Do a challenge** (25–45 min): implement something small
3. **Retrieval test** (5–10 min): close notes and write from memory:
   - what you built
   - why it works
   - how to debug it
4. **Log** (2 min): one sentence in the lab note + one commit

## Spaced review schedule (lightweight)
- Same day: 2-minute retrieval summary
- +2 days: redo a similar task without notes
- +7 days: do a mixed-topic challenge (interleaving)
- +21 days: capstone end-to-end run + review failures

## “Desirable difficulty” rule
If it feels **a bit** hard, you’re probably learning. If it feels impossible, reduce scope.

## Motivation / sticking with it
- **Autonomy:** choose your capstone domain and pick challenges that feel meaningful.
- **Competence:** keep tasks small enough to win daily.
- **Relatedness:** share weekly demos with *someone* (even a friend/Discord) and write a tiny postmortem.
