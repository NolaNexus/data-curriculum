# Patches and add-ons

This folder tracks add-on packs and patch instructions.

## How to use
- Prefer **additive** patches (new notes/templates) to avoid merge conflicts.
- Keep a short changelog of what you merged and when.

## Suggested workflow
1. Read the patch instructions file.
2. Merge folders into the vault.
3. Update module indexes to link new items.
4. Mark the patch as applied in your logbook.
