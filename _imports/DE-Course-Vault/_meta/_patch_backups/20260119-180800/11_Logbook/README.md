# Logbook (how to use)

This folder is your evidence trail: proof that you are building, not just studying.

## What to log
- Gate runs: `10_Logbook/Gate_Runs/`
- 30-day practice: `10_Logbook/30_Day_Practice/`
- Weekly reviews: `10_Logbook/YYYY-W##.md`
- Cloud cost checks: `10_Logbook/Cloud_Cost_Checks/`

## The 60-second rule
After every session, write **one sentence**:
- what changed
- what broke
- what you’ll do next

That’s enough to keep momentum and prevent “where was I?” resets.
