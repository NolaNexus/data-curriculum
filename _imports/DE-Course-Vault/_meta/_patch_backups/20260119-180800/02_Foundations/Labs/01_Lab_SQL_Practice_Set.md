# Lab objective
Build a small dataset and prove joins + window functions work.

# Steps
1. Create:
   - `customers` (unique customer_id)
   - `orders` (many orders per customer_id)
2. Join and verify row counts.
3. Rank orders by date per customer.

# Success criteria
- [ ] You can state the grain of each table
- [ ] You can show row-count checks before/after
