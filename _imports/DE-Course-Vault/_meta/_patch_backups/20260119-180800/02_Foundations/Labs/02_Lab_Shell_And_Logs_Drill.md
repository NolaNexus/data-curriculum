# Lab — Shell + logs drill

## Goal
Learn to debug a failing command like a calm wizard.

## Tasks
- [ ] Create a log file, append to it, and follow it with `tail -f`
- [ ] Pipe a command into `grep` and `wc -l`
- [ ] Run a small Python script, redirect stdout+stderr to a file
- [ ] Use `find` to locate files created in the last day
- [ ] If on systemd: inspect a service and view logs with `journalctl`

## Evidence
- Paste 5–10 lines of commands you ran
- Paste the final log snippet

## Retrieval check (no notes)
- When would you use `tail -f` vs `journalctl -f`?
