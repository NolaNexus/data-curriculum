# Goal
Understand raw → silver → gold layering.

# Key ideas
- Raw is immutable: keep it, even when parsing fails.
- Silver is cleaned + typed + de-duplicated.
- Gold is business-facing models (facts/dims, metrics-ready).

# Checks
- I can explain why “raw overwrite” is a reliability bug.
